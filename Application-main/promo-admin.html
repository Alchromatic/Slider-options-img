Promo Codes

Generate codes that give free images. A signed-in user enters one under Have a code? on the Pricing page; the images are added to their credits and the use is recorded against their account.

Generate codes

1 = one person. Each user can use a code once.

More options

A custom code is one code (number of codes is ignored). Give it more uses to share it with many people.

The CSV includes a sign-up link per code (pricing.html?code=…) that fills the code in for the user.
